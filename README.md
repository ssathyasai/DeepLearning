# Deep Learning

This repository contains comprehensive implementations of various deep learning architectures and concepts from fundamentals to advanced transformer models.

## Contents

### Neural Network Fundamentals
- **Perceptron/** - Basic perceptron implementation and tasks
- **ANN/** - Artificial Neural Networks with forward and backward propagation

### Convolutional Neural Networks
- **CNN/** - Convolutional Neural Network implementations and tasks for image processing

### Recurrent Architectures
- **RNN/** - Recurrent Neural Networks with datasets, notebooks, and tasks
- **LSTM/** - Long Short-Term Memory networks with practical implementations
- **GRU/** - Gated Recurrent Units combining LSTM and GRU concepts
- **Bi-Directional Concept/** - Bidirectional implementations for LSTM, RNN, and GRU

### Advanced Architectures
- **Transformers/** - Complete transformer architecture including:
  - Attention Mechanism
  - Self Attention
  - Positional Encoding
  - Encoder-Decoder architecture
  - BERT (Bidirectional Encoder Representations from Transformers)
  - GPT (Generative Pre-trained Transformer)
  - Full Transformer implementation

## Topics Covered
- Neural network fundamentals and backpropagation
- Computer vision with CNNs
- Sequential data modeling with RNNs, LSTMs, and GRUs
- Attention mechanisms and transformers
- State-of-the-art NLP architectures (BERT, GPT)
